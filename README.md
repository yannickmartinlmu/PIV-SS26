Just clone the Repo and follow the instructions below. 


## Similarity
Just open _index.html_ in your browser and you are good to go.

## Interactive Story Draft
This project uses React, so you need to have node.js installed. \
Then inside the 'Interactive Writing' directory, run `npm install` and then `npm run dev`. \
This should give you some localhost address that you can then open in your browser.
